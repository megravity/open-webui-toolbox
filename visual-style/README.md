# Open WebUI visual style

This directory collects the visual identity and reference assets for this Open WebUI instance. It can grow to cover other visual elements as they are defined; the only established guidance so far is the model icon family.

- [Model icon family](icons/README.md): version 1.0 specification, reference icons, and a reusable creation prompt.

The supplied references are the visual authority for the icon family. The colors and proportions in the specification are approximate guides, not exact measurements or a general-purpose interface theme.
